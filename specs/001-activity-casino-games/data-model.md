# Data Model: Казино-игры в Discord Activity

## Постоянные данные (Postgres)

### `casino_bets` (новая)

| Поле | Тип | Правила |
|---|---|---|
| `id` | TEXT PK | id ставки от клиента (UUID, до 64 символов) или серверный id партии/раунда |
| `guild_id` | BIGINT NOT NULL | |
| `user_id` | BIGINT NOT NULL | повтор с чужим `user_id` отклоняется |
| `game` | TEXT NOT NULL | `roulette` / `plinko` / `blackjack` / `rocket` |
| `stake` | INTEGER NOT NULL | 10–10 000 фантиков (удвоение в блэкджеке не выше 10 000) |
| `multiplier` | NUMERIC(8,2) NOT NULL | итоговый множитель, 0 при проигрыше |
| `payout` | INTEGER NOT NULL | ставка × множитель после случайного округления |
| `result` | JSONB NOT NULL | ответ клиенту для повторного показа |
| `created_at` | TIMESTAMPTZ NOT NULL DEFAULT now() | |

Игры пишут только в `casino_bets`, учёт отжиманий (`entries`) не трогают. `INSERT ... ON CONFLICT (id) DO NOTHING` + чтение сохранённого результата при конфликте.

## Данные в памяти процесса

### Сессия

`token → {userID, guildID, name, expires}`. Срок 24 часа. Теряется при перезапуске (клиент входит заново).

### Партия блэкджека

| Поле | Описание |
|---|---|
| `id` | случайный id, он же id в `casino_bets` |
| `guildID`, `userID` | ключ: одна активная партия на игрока |
| `stake` | ставка; ×2 после «Удвоить» |
| `deck` | оставшиеся карты, клиенту не отдаются |
| `player`, `dealer` | карты; вторая карта дилера скрыта до конца |
| `seq` | номер шага, растёт на каждое действие |
| `timer` | автоматическое «Хватит» через 2 минуты без хода |

Переходы: `playing` → (`hit` → `playing` | `bust`) / (`stand` → итог) / (`double` → итог). Итог: `blackjack` x2.5, `win` x2, `push` x1, `lose` / `bust` x0. Начальный блэкджек у игрока или дилера завершает партию сразу. После итога партия удаляется из памяти, результат — в `casino_bets`.

### Раунд рокетки

| Поле | Описание |
|---|---|
| `id` | случайный id, он же id в `casino_bets` |
| `guildID`, `userID` | одна активная ракета на игрока |
| `stake`, `auto` | ставка и автовывод (0 — нет) |
| `crash` | точка взрыва, клиенту не отдаётся до конца |
| `started` | время старта по часам сервера |
| `done` | канал, закрывается при завершении (для долгого опроса) |

Переходы: `flying` → `won` (вывод при `m(t) < crash` или автовывод при `auto < crash`) | `crashed`. Таймер на момент взрыва (`ln(min(crash, auto)) / 0.06` с) завершает раунд сам. После завершения раунд хранится в памяти ещё 1 минуту для долгого опроса.

## Правила проверки (общие)

- Ставка — целое 10–10 000 (FR-002).
- Рулетка: `kind` из списка; `value` 0–36 для `number`, 1–3 для `dozen`.
- Plinko: `rows` 8–16, `risk` ∈ {low, medium, high}.
- Рокетка: `auto` = 0 или 1.01–100.
- Блэкджек: `action` ∈ {hit, stand, double}; `double` только на двух картах.
