# Бот-трекер отжиманий

## Команды

| Команда | Что делает |
|---|---|
| `/owe @user 30 [за что]` | Назначить участнику отжимания (проигранный спор) |
| `/done 20` | Записать сделанные отжимания (минимум 10 за раз) |
| `/status [@user]` | Сколько осталось / сделано / назначено |
| `/top` → «должники» или «сделано» | Лидерборд за последние 365 дней |
| `/history [@user]` | 10 последних записей (видно только тебе) |
| `/undo` | Отменить свою последнюю запись (старые броски колеса лудомании отменить нельзя) |
| `/casino` | Открыть казино на фантики: рулетка, Plinko, блэкджек, рокетка |

**Осталось** = назначено − сделано за последние 365 дней (не меньше 0).
Долги старше года «сгорают» вместе с отжиманиями того же периода.

### Dota 2

| Команда | Что делает |
|---|---|
| `/linkdota @user <id>` | Привязать Dota-аккаунт (Friend ID, Steam64 ID или ссылка Dotabuff/OpenDota) |
| `/unlinkdota @user` | Отвязать |
| `/dotalinks` | Список привязок |
| `/calculate_dota` | Посчитать новые матчи прямо сейчас |

Бот сам проверяет матчи каждые `DOTA_CHECK_MINUTES` минут и пишет результат в канал `DOTA_CHANNEL_ID`.
Считаются только **пати-игры**, где играли минимум 2 участника, привязанных к началу матча, длиннее 10 минут;
каждый матч — один раз. Для каждого игрока матчи считаются **с момента привязки его аккаунта**
(повторная привязка того же аккаунта момент не сдвигает).

KDA = (убийства + ассисты) / смерти (если смертей 0 — делим на 1):

| KDA | Отжимания |
|---|---|
| ≥ 4 | 0 |
| ≥ 3 | 10 |
| ≥ 2 | 20 |
| ≥ 1 | 30 |
| > 0 | 50 |
| = 0 | 70 |

Матчи берутся из [OpenDota](https://www.opendota.com). У каждого игрока в Dota 2 должно быть включено
**Настройки → Сообщество → «Открыть общий доступ к данным матчей»** (Expose Public Match Data),
иначе его матчи не видны. Новые матчи появляются на OpenDota с задержкой — обычно до получаса.

### PUBG

| Команда | Что делает |
|---|---|
| `/linkpubg @user <ник>` | Привязать PUBG-аккаунт (ник с учётом регистра, Steam) |
| `/unlinkpubg @user` | Отвязать |
| `/pubglinks` | Список привязок |
| `/calculate_pubg` | Посчитать новые матчи прямо сейчас |

Очки за матч: **100 за килл + 50 за ассист + 1 за единицу урона**. Набрал **300+** — без отжиманий, иначе **10**.
Считаются обычные и рейтинговые матчи (без аркад, кастомок и тренировок), начатые после привязки игрока,
где в **одной команде** было минимум 2 привязанных участника. Автопроверка — вместе с Dota, отчёты в тот же канал.
Матчи PUBG учитываются в ролях и в счётчике «больше 10 пати-игр» вместе с Dota.
Нужен ключ `PUBG_API_KEY` с developer.pubg.com.

### Государство

| Команда | Кто | Что делает |
|---|---|---|
| `/founder @user` | админ | Назначить гражданина-основателя |
| `/vouch @user` | гражданин | Поручиться (только за тех, кто на сервере 14+ дней). 2 поручителя + долг < 100 + сделано > 0 → гражданство |
| `/citizens` | все | Список граждан (👑 президент, ❄️ заморожен, 🚫 маргинал) |
| `/accuse @user N за что [часы]` | гражданин | Суд. Виновен → N отжиманий обвиняемому, иначе обвинителю (клевета) |
| `/revoke @user [часы]` | гражданин | Лишение гражданства, нужно ⅔ граждан |
| `/marginal @user [часы]` | гражданин | Маргинал — получает роль «Маргинал» |
| `/propose текст` | гражданин | Референдум о законе на 1 день, простое большинство |
| `/laws` | все | Конституция и принятые законы |
| `/election` | гражданин | Выборы президента: сутки выдвижения + сутки голосования |
| `/nominate` | гражданин | Выдвинуть себя во время выборов |

- Голосуют только граждане кнопками под сообщением. Голос окончательный — поменять его нельзя.
- **Заморозка:** при долге больше 300 бот отклоняет все гражданские действия, пока долг не уменьшится.
  Замороженные не считаются в порогах голосований.
- **Суд:** адвокат — случайный гражданин (не обвинитель и не обвиняемый), голосовать может.
  Обвиняемый не голосует. Виновен, если «за» больше половины граждан (без обвиняемого).
- **Президент** — минимум 30 дней до перевыборов. Его нельзя обвинить, лишить гражданства или сделать маргиналом.

### Роли по итогам игр
Учитываются только отжимания, **назначенные** за пати-матчи и по приговорам суда.
Участвуют только граждане без заморозки, сыгравшие **больше 10 пати-игр** за период.

- **Топ руинер / Порядочный гражданин** — больше всех / меньше всех назначено за последние 30 дней (обновляется раз в час).

Роли бот создаёт сам. Ему нужно право **«Управлять ролями»**, и его роль должна быть **выше** этих ролей
в **Настройки сервера → Роли**.

## Настройка

### 1. Discord
https://discord.com/developers/applications → **New Application** → вкладка **Bot** → **Reset Token**, скопируй токен.
Вкладка **OAuth2 → URL Generator**: отметь `bot` и `applications.commands`, права — `Send Messages`, `Embed Links`.
Открой ссылку и добавь бота на сервер.

### 2. Supabase (база данных)
1. https://supabase.com → **New project**. Запомни пароль базы.
2. Вверху проекта нажми **Connect** → выбери **Session pooler** → скопируй строку подключения.
   (Direct connection работает только по IPv6 — на хостингах часто не подключится.)
3. Вставь её в `DATABASE_URL`, заменив `[YOUR-PASSWORD]` на пароль.

Таблицу `entries` бот создаст сам при первом запуске. Данные можно смотреть в Supabase → **Table Editor**.

> На бесплатном тарифе Supabase ставит проект на паузу после ~7 дней без запросов.
> Пока бот запущен и им пользуются — это не грозит; если всё же уснул, нажми **Restore** в панели.

### 3. `.env`
Скопируй `.env.example` в `.env` и заполни `DISCORD_TOKEN`, `GUILD_ID`, `DATABASE_URL`.

## Запуск локально
Нужен Go 1.26 или новее и файл `.env` по образцу `.env.example`.
```
go run .
```

## Тесты
```
go test ./...
```
Тесты ходят в базу из `DATABASE_URL` и откатывают все изменения, но на время работы блокируют таблицы.
Поэтому запускай их на своей тестовой базе, а не на боевой. Для разработки заведи и своего тестового бота.

## Структура проекта
```
main.go                точка входа: Discloud собирает проект из корня
internal/config        настройки из переменных окружения и .env
internal/store         база: схема, запросы, статистика отжиманий
internal/store/storetest  тестовая база в откатываемой транзакции
internal/shared        мелкие общие функции
internal/bot           Discord-бот: отжимания, Dota 2, PUBG, гражданство, голосования, роли
internal/casino        казино: HTTP API игр для Discord Activity
activity/              страница казино (TypeScript), собранная версия в activity/dist
cloudflare/worker.js   прослойка между Discord и Discloud
docs/specs/            спецификация казино
```

## Деплой на Discloud
Бот и казино работают одним приложением-сайтом на Discloud (тариф Platinum, поддомен `pushups`).
Discloud сам собирает Go-проект (`go mod download`, `go build`) по `discloud.config` и обновляет приложение
после каждого пуша в `main` через GitHub-интеграцию.

Секреты хранятся в переменных окружения приложения на Discloud, в репозиторий их не коммитить:
`DISCORD_TOKEN`, `DATABASE_URL`, `GUILD_ID`, `DOTA_CHANNEL_ID`, `PUBG_API_KEY`,
`ACTIVITY_PORT=8080` (порт сайта на Discloud), `DISCORD_CLIENT_SECRET` (OAuth2 приложения в Discord).

После обновления проверь логи: все строки бота начинаются с `[GO]`, при запуске есть `Запущен как ...`
и `Казино: порт 8080`. Если в логе сборки шаг `go build` помечен `CACHED`, хотя код менялся,
Discloud взял старую сборку: тогда пересоздай приложение (данные в Supabase не пострадают,
переменные окружения придётся добавить снова).

### Страница казино
Discloud собирает только Go, поэтому собранная страница `activity/dist` хранится в репозитории.
После изменений в `activity/src` пересобери её и закоммить вместе с кодом:
```
cd activity
npm ci
npm run build
```

### Cloudflare Worker
Discloud отдаёт сайт с заголовком `X-Frame-Options` (`SAMEORIGIN`), из-за которого Discord не может показать казино
во встроенном окне. Поэтому между ними стоит воркер [cloudflare/worker.js](cloudflare/worker.js)
на `pushups.zaptot.workers.dev`: он пересылает запросы на `pushups.discloud.app` и убирает этот заголовок.
В Discord Developer Portal → Activities → URL Mappings: `/` → `pushups.zaptot.workers.dev`.
Код воркера правится в панели Cloudflare (Workers & Pages → pushups → Edit code).
